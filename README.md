# Unit-Converter

## Unit Converter (EN)

Available by default on http://127.0.0.1:5000

A web application for quickly and easily converting values ​​between different units of measurement. Supports conversion of length, mass, and temperature.

## Features

- **Instant conversion** — convert values ​​in real time or at the click of a button.
- **Large selection of units** — metric, imperial, and other measurement systems are supported.
- **Intuitive interface** — two panels: data entry and result display.
- **Flexible customization** — easily add new categories and units of measurement.
- **Responsive design** — displays correctly on all devices (PCs, tablets, smartphones).

## Technologies

- **Backend**: Python, Flask
- **Frontend**: HTML5, CSS3, JavaScript (Jinja2 for templates)

## Installation

The application requires [Python](https://www.python.org/downloads/)

1. Cloning repository:
```bash
git clone https://github.com/ChurinKirill/Unit-Converter.git
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python app.py
```

The console output will indicate the address the application is running on, for example:
`Running on http://1.1.1.1:5000`

## Конвертер единиц измерения (RU)

Доступен по умолчанию на http://127.0.0.1:5000

Веб-приложение для быстрого и удобного перевода значений между различными единицами измерения. Поддерживает конвертацию длины, массы, температуры.

## Возможности

- **Мгновенная конвертация** — перевод значений в реальном времени или по нажатию кнопки.
- **Большой выбор единиц** — поддерживаются метрические, имперские и другие системы измерений.
- **Интуитивный интерфейс** — две панели: ввод данных и отображение результата.
- **Гибкая настройка** — можно легко добавлять новые категории и единицы измерения.
- **Адаптивный дизайн** — корректно отображается на всех устройствах (ПК, планшеты, смартфоны).

## Технологии

- **Backend**: Python, Flask
- **Frontend**: HTML5, CSS3, JavaScript (Jinja2 для шаблонов)
